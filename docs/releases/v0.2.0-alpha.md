# xXASSXx 0.2.0 Alpha

本版集中改进小团队的跨成员任务协作：从确认需求、交给正确成员，到受限写入和运行，再把结果带回原对话。

## 主要变化

- 持久任务卡保存原始需求、修订、确认、问题与结果。可在同一任务中澄清、恢复或重开，不必重新解释上下文。
- 修复远程任务误用发起方目录、确认误作修改、材料阶段衔接及远程重试等问题；任务始终由指定成员在自己的机器上执行。
- 默认只读。需要写入或运行时，由执行成员在自己的终端为当前任务版本允许独立工作目录，原文件及额外依赖保持只读。
- 执行方按 **CtrlT → Enter → 允许并开始**，任务自动继续，发起方不需要重试。可以在同一页调整保存位置、只读依赖和运行时限；等待授权不消耗执行重试次数。
- 完成任务不再显示遗留“等待”，任务卡明确区分本机对话目录与执行成员；结果包含实际文件引用和校验信息。
- 信箱支持持久任务协调事件、进展汇总和会议/日报调度；后台继续处理任务，退出界面不会停止后台。
- 新增开发调试要求：涉及界面、卡住、授权、执行归属和答复的修复，必须亲自操作真实终端并看到有意义的最终回答。

## 安装与升级

下载匹配系统架构的安装包、`SHA256SUMS` 和 `install.sh`，放到同一文件夹：

```sh
sh install.sh --from .
xxassxx --version
```

也可使用本 Release 的安装器下载指定版本：

```sh
sh install.sh --version v0.2.0-alpha
```

版本输出应为 `xxassxx 0.2.0-alpha`。已有个人端请先等正在执行的任务结束，运行 `xxassxx client stop` 并退出旧界面，再安装并重新打开。数据库增量迁移到 schema 8，保留身份、配置和历史；迁移后的数据库不能交给旧程序使用。团队信箱也需要使用本版程序。

## 验证与边界

发布前完整自动回归为 111 项通过，另外两项旧真实模型测试默认跳过。真实 Mac → Trader → Lakota 终端测试已完成只读任务、独立目录内修改 SRV 副本及 MOOSE 对照正演，以及界面授权后自动写文件/计算/回传结果。证据与具体构建见 `docs/current-state.md`；发布构建的多平台测试以本标签的 Actions 结果为准。

这是 1.0.0 前的小规模测试版本。原文件直接修改、跨机器原始文件自动传输、自动更新和开机自启尚不支持；macOS 安装包未签名或公证。科研测试证明协作流程与指定小规模计算能完成，不代表现场预测精度。模型答复仍需要事实核对；已发现将模型坐标方向擅自解释成地理方向的表述问题，尚未宣称解决。
