# 0.4.0 Alpha：成员自动同步与真实交付进度

新成员登记后，已有客户端自动更新团队名单；处理任务和交付附件时，界面明确显示当前状态、已等待时间及下一步责任人。

## 新增与修复

- 信箱的持久化成员表成为团队名单来源，已鉴权客户端自动同步 ID 和显示名。侧边栏和 `@` 候选实时更新，离线成员仍可见，无需重导邀请或重启界面；名单插入保持当前所选成员。
- 输入区上方显示真实任务进度和等待时间，区分处理、等待成员、待授权、失败及信箱断线；完成后结束等待提示。
- 附件状态按实际传输记录显示待发送方允许、上传、接收与完成。接收方没有可下载文件时，明确说明由谁处理，避免把人引到空下载列表。
- 修复等待附件导出许可时被误判为继续执行、重复启动 Codex 的问题。附件实际收到后才审核交付结果，保留内容审核。
- 附件页仅显示当前可用操作，准备阶段的历史说明与当前状态分开标注。

## 安装与升级

提供 Apple Silicon macOS、Intel macOS、Linux x86_64 三个平台的归档包，以及 `install.sh` 和 `SHA256SUMS`。

```sh
# 已下载对应包、安装器和校验文件到同一目录
sh ./install.sh --from .
xxassxx --version
```

在线安装请显式指定预发布版本：`sh install.sh --version v0.4.0-alpha`。

先升级团队信箱，再升级个人端。个人端先等待正在运行的任务结束，停止后台并退出旧界面，更新程序后重新打开。数据库仍为 schema 9；从 0.3.2-alpha 升级保留身份、配置、白名单和历史，无需重新初始化或更换邀请。使用自定义安装目录时，为安装脚本传入原 `--prefix`。

成员自动同步需要信箱和客户端均更新；旧客户端仍能通信，但不会自动更新联系人。新客户端连接旧信箱或断网时保留已有联系人缓存。团队登记仍由管理员管理，不提供自助注册或成员增删命令，当前最多九名成员。

## 验证

功能源码已通过 136 项默认回归，2 项既有 opt-in 测试保持忽略，格式和 Clippy 检查通过。发布构建另由 CI 在三个目标平台运行测试和安装检查。

- 实际 PTY、现用 HTTPS、真实 DeepSeek/Codex 完成 Lakota → MBA PNG 交付，界面最终答复与原件、收件、另存文件哈希一致，并实际打开查看图片。
- 保持老客户端界面打开，在隔离团队后来登记新成员，亲眼看到侧边栏和 `@` 候选刷新，再完成与新成员的真实只读任务并收到正确答案。

实测使用发布前同一功能源码的补丁构建；发布记录单独核对最终安装包和版本，未将版本号调整当作重新执行科研计算。详见[附件与进度验收](https://github.com/shenyaojin/xXASSXx/blob/main/docs/issues-1-2-validation.md)和[成员目录验收](https://github.com/shenyaojin/xXASSXx/blob/main/docs/member-directory-validation.md)。

本版不提供端到端加密、目录实时同步或自动安装更新。目录读取、逐任务写入/运行和附件导出仍是分别授权的范围。
