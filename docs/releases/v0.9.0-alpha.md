# 0.9.0-alpha

开发候选版，尚未公开发布或替换日常安装。

- 新增 `/codex`：选白名单目录进入交互式 Codex，退出后恢复原会话。
- 新增 `/activity` 团队动态：白名单任务的目标、进展、最终结果、来源和下一步责任对全部团队成员可见。
- 新任务等待执行端在线并支持团队动态后派发；断线结果保留去重恢复。
- 新共享只读任务绑定显式白名单；Full access 的系统根目录不自动公开。
- Ask for approval 改为批准整项任务一次，覆盖所需读写、运行、联网、依赖安装、本机凭据使用和指定成果发送。
- 当前任务聊天可直接回答待处理问题；分开显示答案提交、执行方接收和续接，不以模型回复代替真实状态。
- 支持先发送阶段附件、等待外部操作后继续同一任务，例如交付公钥后克隆仓库。
- 私人收件箱和旧任务不自动公开；历史受限授权不自动扩大，新任务版本仍需批准。

个人库 schema 12，信箱 schema 3；升级前备份，需手动进行跨 schema 升级。支持 Apple Silicon Mac 和 Linux x86_64 musl。

Lakota → Trader → 非参与成员的真实任务与手动原生 Codex 入口已验收，详见 [使用与验收](../team-activity.md) 和 [精简证据](../team-activity-evidence.json)。开发候选验证不代表已发布或已部署。
