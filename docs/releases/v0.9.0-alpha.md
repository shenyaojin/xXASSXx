# 0.9.0-alpha

开发候选版，尚未公开发布或替换日常安装。

- 新增 `/codex`：选白名单目录进入交互式 Codex，退出后恢复原会话。
- 新增 `/activity` 团队动态：白名单任务的目标、进展、最终结果、来源和下一步责任对全部团队成员可见。
- 新任务等待执行端在线并支持团队动态后派发；断线结果保留去重恢复。
- 新共享只读任务绑定显式白名单；Full access 的系统根目录不自动公开。
- 私人收件箱、旧任务、执行授权和文件发送权限保持独立。

个人库 schema 11，信箱 schema 3；升级前备份，需手动进行跨 schema 升级。支持 Apple Silicon Mac 和 Linux x86_64 musl。

验证记录将在完成真实跨机器验收后附于 `docs/team-activity-evidence.json`。
