# 0.7.1-alpha

本版修复 Lakota 实际聊天中发现的三个问题，支持 M 系 Mac 和 Linux x86_64。

- **普通问答正常结束**：能力说明等不需要文件的答复，以及没有找到匹配材料的说明，可以直接提交审核，不再因为空文件清单反复失败或追问。真正的文件分析仍读取冻结副本。
- **被拒绝的补充要求不再中断原任务**：执行方不能直接修改发起人的目标，界面会说明原因；拒绝该操作时保留正在运行的任务和有效授权。
- **修复 zsh 临时文件错误**：隔离执行将 here-document 使用的临时文件放在获准任务目录内，不扩大文件或联网权限。
- 三份内置 Codex 技能更新至 0.1.3，与无文件答复合同保持一致。

## 升级

已安装正式 `0.7.0-alpha` 的用户，在没有运行任务时退出界面、停止后台并备份个人数据和旧程序，然后使用：

```sh
xxassxx update --source https://github.com/shenyaojin/xXASSXx/releases/download/v0.7.1-alpha
```

也可下载本版两个平台中对应的安装包，以及 `SHA256SUMS`、`update.json`、`update.json.sig`，放在同一目录，执行 `xxassxx update --from 该目录`。更新器验证签名、架构和完整性。首次安装使用发布附件 `install.sh`，参见 [成员安装](https://github.com/shenyaojin/xXASSXx#成员安装)。

个人库仍为 schema 10；身份、配置、目录授权、任务和收件记录保留，无需重新初始化或重新导入邀请。此前未公开、使用测试签名公钥的本地候选包仍需先手动更换为正式签名版本。

## 验证与已知限制

本次修复已在 Lakota 通过 175 项自动回归（2 项既有忽略）、Clippy，以及真实 DeepSeek／官方 Codex 的双端交互终端验收；文件内容与最终答复均核对。发布流水线另对 M 系 Mac 和 Linux 运行测试、优化构建及独立目录安装检查。详细证据见 [聊天错误验收](https://github.com/shenyaojin/xXASSXx/blob/main/docs/chat-errors-validation.md)。

本版没有解决偶发心跳或同步超时，也未重跑已取消的科研计算。客户端仍无邀请成员按钮或成员增删命令；现有团队由管理员在信箱端登记成员并生成独立邀请。
