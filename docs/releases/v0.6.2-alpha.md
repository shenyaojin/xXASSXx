# 0.6.2-alpha

对话增加日期和时间；文件收发使用明确的成员标题、文件名和易读大小。同一批文件的等待、传输和收取通知合并为一条记录，实时显示当前状态，错误仍保留。普通助手回复不再显示“助手 · 消息”。收件箱同步精简文件记录。

后续支持 M 系 Mac 和 Linux x86_64，停止 Intel Mac 构建、发布和验收。保持个人库 schema 10、信箱 schema 2，不改变文件权限和原始历史。

本文件记录本地安装批次，尚未公开发布。已安装到本机 owner 与 Lakota test；操作见 [界面说明](../ui-experience.md)，验证见 [本轮验收记录](../conversation-validation.md)。
