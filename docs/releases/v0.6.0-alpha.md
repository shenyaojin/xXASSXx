# 0.6.0-alpha

成员拥有持久收件箱。终端输入 `/inbox` 查看普通留言、任务记录和待处理事项，可以发送和回复普通留言；断线时保留缓存，恢复连接后补发。本人未读由明确的阅览动作清除，后台同步或 dot 读取不会代替本人确认。

新增基于 OAuth 的成员 MCP 接口，支持身份、联系人、收件箱读取与普通留言。真实 OpenAI 连接已在隔离测试团队完成授权、读取、回复及令牌刷新；尚未接入日常团队数据。保留此前更新器功能。

本版个人数据库由 9 升至 10，信箱由 1 升至 2。管理员须停服并保存可恢复副本，先升级信箱，再升级个人端；不能通过只换回旧程序回退。现有自动更新器仅处理相同数据库版本。

此文件用于本地安装批次，尚未公开发布。部署、实际终端操作与平台验证边界见 `docs/current-state.md`。
