# xXASSXx 0.1.0 Alpha

首个 Alpha 版本。程序版本号：`0.1.0-alpha`；发布标签：`v0.1.0-alpha`。

面向十人以下小团队的本地知识版本管理、个人 local agent 对话与受控 Codex 协作。本版按最新代码重新构建，替代此前同版本的本地安装包，版本号保持不变。

## 本版功能

- 独立 Rust 终端界面，持久保存本人对话、同伴消息、任务和来源；通过 `@成员` 联系对方 local agent，显示本地时间和成员活跃状态。
- 本地 SQLite 与不可变内容快照，支持版本历史、差异、SHA-256 校验和导出。
- 团队信箱、私人邀请、个人端初始化、后台 local agent 与临时断网重连。
- DeepSeek、Ollama 和兼容工具调用接口的可配置接入；复杂任务使用用户自己的官方 Codex 登录。
- 按具体文件授权的只读协作、澄清与原会话续接；任务结果和来源持久保存。
- 在已授权目录内，通过 Codex 原生工具只读查找、查看和解释文件；本地与同伴请求的结果回到原会话，包含相对文件引用，无须先导入快照或提供对象 ID。
- 首次在未授权的项目目录启动时询问是否加入白名单并记住选择，后续通过 CtrlR 管理；同伴请求不能扩大已有白名单。

## 安装

Apple Silicon Mac 的本机构建位于 `dist/v0.1.0-alpha/`。可将整个离线 ZIP 包交给同架构用户，解压后进入目录执行：

```sh
sh install.sh --from .
export PATH="$HOME/.local/bin:$PATH"
xxassxx --version
xxassxx client init --help
```

输出应为 `xxassxx 0.1.0-alpha`。初始化需要管理员提供个人邀请；模型配置与 Codex 登录各自完成。

GitHub 预发布上线后，可下载该 Release 的 `install.sh` 并显式选择版本：

```sh
sh install.sh --version v0.1.0-alpha
```

Alpha 安装请使用明确的版本参数，不依赖默认稳定版 `latest`。安装器核对 `SHA256SUMS` 后安装到 `~/.local/bin`，支持 `--prefix` 选择其他目录。

## 从此前本地预览包升级

本版数据库升级到 schema 6。先运行 `xxassxx client stop` 停止旧后台，并备份个人端数据库、内容库和配置，再安装新包。新程序打开数据库时完成迁移；迁移后的数据库不能直接交给旧二进制使用，即使两个安装包显示相同的 `0.1.0-alpha`。本次构建仅更新分发产物，安装和服务重启需另行执行。

## Alpha 范围与限制

- 本次本机构建目标为 Apple Silicon macOS。CI 配置另有 Intel macOS 与 Linux x86_64 musl，须在相应任务成功后才有对应安装包；Windows 不支持。
- macOS 包尚无 Developer ID 签名或公证。
- 现阶段没有自动更新、跨机器原始文件传输、共同编辑或任意代码执行能力。
- Alpha 期间接口和数据格式可能继续调整；升级前应备份数据库、内容库和配置。
- 安装包不包含个人邀请、凭据、数据库或业务文件。首版构建不改变现有常驻服务。

既有功能验收记录见仓库 `docs/phase5-validation.md`；本版构建检查与产物说明见 `docs/releasing.md`。真实模型历史验收与本次默认自动测试分开记录。
