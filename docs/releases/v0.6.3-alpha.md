# 0.6.3-alpha

新增手动停止任务：在任务中使用 CtrlX 或 /stop，填写原因，选择“停止并归档”或“仅停止”。进行中列表按 a 也可进入停止并归档表单；Esc 返回保留原输入，归档记录可查看原因与原文件。

发起人停止整个任务并通知执行成员；参与人可停止本机参与并告知发起人。停止直接在本机生效，不等待模型理解或网络恢复；远端收到通知后停止。运行中的本机执行会退出，迟到的回复不能恢复任务。停止保留已有文件，不会把任务伪装成已完成；恢复归档也不会重启执行。

保持个人库 schema 10、信箱 schema 2。支持 M 系 Mac 和 Linux x86_64。此文件用于本地安装批次，尚未公开发布。
