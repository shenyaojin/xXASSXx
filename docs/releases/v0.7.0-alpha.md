# 0.7.0-alpha

支持 M 系 Mac 和 Linux x86_64。从 0.4.0-alpha 升级可获得以下功能；不再提供 Intel Mac 安装包。

- **访问模式**：`/access` 选择 Ask for approval 或 Full access。默认逐项批准；Full access 允许本机文件读写、运行及联网，明确任务、执行和文件发送自动继续。每位成员只控制自己电脑的权限。
- **手动重连**：`/reconnect` 立即尝试恢复连接。临时断线会自动退避重试；重连不会重跑已经完成或结果不确定的任务。
- **任务更容易管理**：输入 `/` 查看命令联想；任务可以手动停止、填写原因并归档。对话显示时间，附件集中显示最新状态、收发成员和下一步操作。
- **成果交接**：内置接任务、执行、成果交接三份 Codex 技能（0.1.2）。已用 Lakota 的真实 DSS 数据验证查找最终结果图、解释结果、批准运行和成果回传。
- **成员收件箱**：`/inbox` 查看协作记录、普通留言与回复，支持离线补收；提供有身份绑定的 OAuth/MCP 接入。
- **签名更新**：`/update` 检查并安装兼容版本，验证签名、平台和文件完整性后再替换程序。

## 安装与升级

下载对应系统的 `.tar.gz`、`SHA256SUMS` 和 `install.sh` 到同一目录，然后执行：

```sh
sh ./install.sh --from .
```

首次安装还需团队邀请和本机模型配置，见 [成员安装](https://github.com/shenyaojin/xXASSXx#成员安装)。

已有用户先确认没有正在执行的任务，退出界面、停止后台，并备份个人数据目录、配置与旧程序，再原位安装。保留原安装前缀和身份，不要重新初始化。0.4.0 没有更新器；本次个人数据库迁移到 schema 10，不能通过旧版自动更新跨 schema 升级。

这是首个公开带签名更新清单的版本。此前未公开的 0.5–0.7 本地候选包使用旧测试公钥，须手动安装一次本次正式发布包，之后才能验证后续签名更新。默认权限仍是 Ask for approval。

## 验证范围

发布工作流在两个平台分别运行自动回归、优化构建和离线安装检查。此前真实模型与终端验收分别记录在 [访问模式与重连](https://github.com/shenyaojin/xXASSXx/blob/main/docs/access-modes-validation.md) 和 [DSS 技能场景](https://github.com/shenyaojin/xXASSXx/blob/main/docs/skills-matrix-validation.md)。发布构建不代表重新运行科研计算。
