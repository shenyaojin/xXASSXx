# 0.5.0 Alpha

- 新增 `xxassxx update --check` 与 `xxassxx update`：从 GitHub Releases、指定 HTTPS 发布目录或离线目录取得新版，验证 Ed25519 签名和 SHA-256 后安装。
- 终端异步检查更新，输入 `/update` 自动下载、等待后台完成当前工作、替换程序并恢复原会话。可选择空闲自动安装。
- 已安装程序通过运行锁避免与其他终端、后台同时替换；新版后台启动失败时尝试恢复旧程序，保留数据库中的新消息。
- 此版自动更新只接受同一数据库 schema，涉及迁移的发布需按该版本说明手动升级。团队信箱由管理员停服升级。

首次启用需使用本版安装器，在停止旧后台、退出旧界面后安装一次；保留原安装前缀及个人数据目录，无需重新初始化。以后使用程序内更新。
