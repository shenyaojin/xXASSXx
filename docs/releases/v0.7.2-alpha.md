# v0.7.2-alpha

修复自然语言发送本机文件时选错执行机器的问题。`@成员` 先作为对方身份交给本机助手判断；发送本机文件使用附件通道，请对方提供文件才创建远端任务。

- 统一 DeepSeek 提示词、工具说明与 Full access 的自动发送行为；支持本机绝对路径、`~/`、工作目录相对路径和 `file://` 地址。
- 已生成附件后，对话使用真实传输状态，不再保留过时的“等待允许发送”操作提示。
- 任务问题中的未绑定绝对路径转换为位置引用，避免描述查找失败时再次被消息校验拦住；不会据此推断文件归属或新增访问权限。
- CtrlY 重试任务列表中当前选中的任务。
- 执行方重试后，发起方同步恢复处理状态。
- Linux 只读执行为安装在私有目录内的 standalone Codex 建立校验过的程序包缓存，保留配套工具与资源，只开放运行文件，保留身份与历史目录的拒绝访问范围。

支持 Apple Silicon Mac 与 Linux x86_64 musl；不改变数据库 schema。发文件的那台电脑也需要升级，单独升级接收端不能修复旧发送端的请求路由。
