# 0.6.4-alpha

修复已有文件交付将参考资料误列为附件的问题。执行助手查阅的状态、说明、日志与实际要发送的文件分开；发图任务支持二进制文件，不再套用文本材料冻结流程。延续任务可复用此前查找结果，先定位已知项目，再查必要依据。

附件页先显示收发成员、当前状态、文件清单和操作入口。长说明及文件路径按 i 查看；上下选择时自动跟随，不会把允许发送按钮挤出屏幕。未开始传输时不再逐项显示“已传 0 字节”，列表浏览时隐藏无关的对话输入框。

个人库 schema 10、信箱 schema 2 不变。支持 M 系 Mac 和 Linux x86_64。本文件记录本地测试安装批次，不代表已公开发布或通过客户端更新器升级。
