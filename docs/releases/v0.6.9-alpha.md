# 0.6.9-alpha

候选版本，源码未提交或公开发布。支持 Apple Silicon Mac 与 Linux x86_64；现用 Mac 和 Lakota 已备份手动安装，并非客户端更新器安装。

- 执行任务准备必须保留明确的成果交付意图；缺少或错误类型的 `deliver_files` 会沿原决策重试流程补正。已经要求“把文件发回来”时，不再把是否交付增加为新问题；本地运行和发送授权独立保留。
- 批准后的提示以实际权限和传输状态为准，避免预告不需要的第二次发送批准。
- 执行方看到的共享最终答复标明发起人，如“给 @owner 的答复”，避免误读收件位置。

三份内置技能仍为 0.1.1。本轮用 Lakota 真实 DSS 完成找位置、解释结果、授权运行、回答后接续、三文件交付及收到附件的只读解释；功能验证分别在 0.6.6 与 0.6.8 完成，最终 0.6.9 仅增加确定性标题并重新打开两端真实终端核对。Lakota 最终自动回归 170 通过、0 失败、2 项既有忽略，格式、Clippy、两平台 release 构建通过。

数据依据、失败后修正、实际交付文件与验证边界见 [真实场景验收](../skills-matrix-validation.md)。
