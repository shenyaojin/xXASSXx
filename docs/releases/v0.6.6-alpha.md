# 0.6.6-alpha

候选版本，源码未提交或公开发布。支持 Apple Silicon Mac 与 Linux x86_64。

- 内置接任务、执行、交接三份 Codex 技能；每轮启动及恢复都提供当前包并记录版本与哈希，不需要用户安装技能。
- 清晰的客户端取已有文件指令可直接开始只读选择；发送方仍须批准固定附件，写入和运行仍需独立授权。
- 新对话可用本人近期已完成文件任务判断命名项目的执行成员；记录只是线索，不替代当前文件依据或权限。
- 最新成果默认按完成记录与最终采用指向选取，避免把新生成的试算图当成最终结果。完成页保留简短说明和真实收件状态。
- listing 使用本轮直接交付合同，不等待不存在的后续分析。

验证与安装事实见 [本轮验收](../one-request-skills-validation.md)。
