# v0.8.0-alpha

local agent 现在可以先在本机允许的目录中定位、读取资料，缺少工具时再携带实际发现交给 Codex。简单问答和文件选取可以直接完成，减少重复查找和不必要的 Codex 执行。

- 支持跨多个白名单列目录、按文件名或小文本内容搜索、分段读取 UTF-8 文本；明确返回搜索范围、截断、行号和文件哈希。
- Codex 交接保留原始请求、实际读取证据与剩余工作；只读任务可以由执行方 local agent 独立提交，也可以在同一次执行中交给 Codex。
- 本机核验或处理文件后，可继续发给请求中指定的联系人。执行成员与收件人分开记录，收到匹配的真实收据后才完成任务。
- 成功保存答复或业务动作后立即结束本轮，避免多余模型请求把已接受的交接误记为失败。收件人 ID 格式错误在产生副作用前进行有界纠正。
- 界面区分 local agent 与 Codex 的执行状态；模型 HTTP 错误保留状态码，便于排查。

沿用现有访问模式：Ask for approval 保留本机审批；由设备主人选择的 Full access 让明确任务、执行及发送免逐次批准。业务目标不明确、模型服务错误或登录失效仍可能暂停。升级不会自动开启 Full access，也不会改变其他机器的权限。

支持 Apple Silicon Mac 与 Linux x86_64 musl；数据库 schema 和更新签名公钥不变。使用 `/update` 检查更新并按提示安装，需要新能力的执行端也应升级。

验证依据：实现提交的 Linux 回归 186 项通过，ARM Mac 与 Linux CI 通过；真实双端终端验证了跨白名单定位后交给 Codex 统计 ZIP 中的 3 条记录、总和 83 并自动发送，以及远端 local agent 不启动 Codex 的取件回传。此次发布只调整版本与发布文档，标签 CI 另行验证正式包，不将安装检查描述成重新运行上述业务。

已知限制：最后一轮真实模型路由矩阵完成 10/24 项后遇到 HTTP 503，未宣称全部通过。历史上传进展仍可能把接收电脑称为“本机”，模型总结也可能不够精确地描述文件所在目录；最终收件人、文件字节和统计结果已核对。详见仓库中的 `docs/local-agent-handoff.md` 与对应证据。
