# 界面与任务归档

适用于本地测试版 `0.6.4-alpha`，尚未公开发布。

主界面优先显示当前对话和待处理任务。已结束任务收进任务列表，长标题只占一行；浏览列表时收起空输入框。权限确认、执行位置、发送失败和最终结果仍保留。

## 常用操作

| 想做什么 | 操作 |
| --- | --- |
| 找命令 | 输入 `/`，用 ↑↓ 选择，Enter 打开；Tab 仅补全，不执行 |
| 过滤命令 | 例如输入 `/ta`，显示任务相关操作 |
| 关闭命令菜单 | Esc，输入内容保留 |
| 查看任务 | `/tasks` 或 CtrlT；Tab 切换进行中、已结束、已归档 |
| 查看原结果 | 选中任务按 Enter；CtrlD 查看详情 |
| 停止任务 | 选中任务按 CtrlX 或输入 `/stop`；填写原因，Tab 切换“停止并归档／仅停止”，Enter 确认 |
| 归档 | 在已结束页选中任务按 `a`，或打开该任务后输入 `/archive` |
| 归档全部已结束任务 | 在已结束页按大写 `A` |
| 恢复 | `/archived`，选中任务按 `a` |
| 查看帮助 | `/help` 或 F1 |

归档只整理本机列表，可以恢复；不删除对话、文件和结果，不停止执行，不清除未读，也不替对方归档。已完成、已停止的任务可直接归档；进行中的任务按 `a` 会先打开停止表单，确认原因后才停止并归档。新版本任务会重新出现。当前没有跨设备同步归档偏好。

收件箱的“全部”隐藏已归档任务，“已归档”能找回它们；“未读”和“需要我处理”仍包含归档任务的相关条目。打开记录不会自动标为已读，继续沿用明确阅览操作。

青色表示入口和选中项，绿色表示完成，黄色表示等待确认或未读，红色表示需要处理的错误。状态同时保留文字，终端的 `NO_COLOR` 设置仍受尊重。

每条消息显示本机时区的日期和时间。收到文件时标题为“@成员 发来的文件”，发出时为“你发给 @成员 的文件”。同一批文件只显示一条记录，状态随传输更新；文件大小显示为 B、KiB 或 MiB。按 CtrlF 查看文件、收取或另存。时间是这条记录最初出现的时间，状态是当前状态；失败原因仍保留。

主对话和收件箱显示文件清单及交付状态，备注和更详细的传输信息可在附件详情中查看。原始历史仍保留用于追溯，界面合并不改变交付状态或权限。

## 手动停止

自己的任务会通知执行成员停止；别人发来的任务可以停止本机参与，将原因告知发起人。已离线的成员收到通知后才会停止。停止不等待模型回复或后台对话队列，本机在途执行会退出；已有文件不会自动回滚，也不会把任务记成已完成。

原因和时间保留在原任务中。“仅停止”放在已结束列表，“停止并归档”放在已归档列表。取消表单可按 Esc，原来尚未发出的输入保留。恢复归档只恢复显示，不恢复执行；需要继续做时由发起人修改要求并重新确认，写入和运行仍需执行方授权新版本。

## 收发文件

CtrlF 查看附件，Enter 打开文件清单。先核对收发成员、文件名及大小，再按 a 允许发送或按 d 下载；上下键选择文件，已在本机的文件按 Enter 打开。操作入口固定显示，长说明及所选文件路径按 i 查看，Esc 返回清单。

请求已有图片等文件时，助手查阅的参考资料留在本地，只有单独选中的交付文件进入发送清单。助手会先使用当前任务此前找到的项目位置，再查必要的状态依据；不会把整批参考资料自动当成附件发送。旧版已经准备的附件批次保留原清单，升级不会偷偷替换其中的文件；文件选错时应修改任务要求并重新确认。

## 实现边界

本次没有数据库迁移。归档偏好保存在既有个人库的 `app_preferences` 中，并关联任务版本；与协调器原有的终态标记、结果归档和授权状态分开。Slash 菜单由客户端直接处理，不需要请求模型。普通留言暂不支持归档。
