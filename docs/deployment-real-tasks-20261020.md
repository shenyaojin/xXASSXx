## 实测发现与通用修复

1. **历史任务拖慢后台心跳**：Lakota 同一认证请求独立执行约 0.4 秒成功，但后台持续 `presence_unavailable`。核对在一轮中两次展开所有任务的完整历史，复制库测量每次约 2.55 秒。`4eecaf2` 改为只读取后台同步和结果文件所需字段；同一库降到 26–37 毫秒，结果版本、旧工作流状态同步和结果文件冲突检查保留。真实服务随后持续更新心跳，等待任务通过原信箱自动接续。没有提高超时。曾用四次真实认证心跳定位问题，T1 首轮在诊断心跳后派发；这不作为持续在线证明。修复后的真实后台心跳与 T1 r2、T2、T3 接续另行核验。
2. **未确认分配被误写成等待停止**：`6453041` 在安排说明中携带旧分配是否已确认的事实，区分“未确认、未派发”“已确认停止并核对副作用”“仍待停止”。旧提议缺少该事实时只说未提供记录，不猜测已停止或仍需确认。此字段仅解释状态，不授予权限、不解除内核停止屏障；无 schema 变更。

新增回归保留每版结果文件、拒绝结果文件被替换；覆盖未确认改派、停止消息与提议数量、接收端解释、旧客户端缺字段，以及已确认旧分配仍必须停止的路径。此前 `4eecaf2` 的 Lakota/Linux CI 均 216 通过、ARM Mac 215 通过，0 失败、3 项既有忽略。最终源码 `6453041` 的 Lakota/Linux CI 均 217 通过、ARM Mac 216 通过，均 0 失败、3 既有忽略。

原始画面、模型和运行事件、每个任务与版本、批准、停止确认、配置前后核对、来源文件哈希及接收端核验均保存在 Git 忽略的 `smoke-output/deployment-real-tasks-20261020/`，远端同名目录位于 `~/xxassxx-tests/`。完整日志和个人数据库不提交。六项任务使用不同运行版本，证据必须按任务对应，不能声称全部在最终构建上重跑。
