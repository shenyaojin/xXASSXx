# 对话 TXT 导出

2026-10-23。新增 `/export`，用于将一次真实协作交给别人阅读。此文描述源码能力；日常客户端是否安装此版本，另看接续摘要。

## 使用

在当前对话输入 `/export`，Enter 导出，Esc 取消。历史对话先通过 `/chats` 打开。默认保存到 `~/Downloads/xXASSXx-exports/`，按 `d` 可编辑绝对目录路径，Enter 完成编辑后再 Enter 导出。成功页显示完整文件路径、时间线条数及快照时间；Enter 或 Esc 返回原对话。长路径与窄终端可用上下键滚动。

文件为 UTF-8 TXT，名称包含本机日期、对话标题及随机标识。目录自动建立，文件以 0600 权限原子保存，不覆盖已有导出；失败保留在面板中，可调整目录重试。导出不调用模型、不联网补取历史、不重新执行任务、不发送文件。

## 记录范围

使用同一数据库读取快照，不受 UI 分页或事件轮询的 500 条限制。正文保留用户和助手原话、完整段落；关联任务包含全部已有版本和本机已保存的远端活动。归档、隐藏的历史不因当前 UI 筛选而消失。仅查询本段会话及其关联任务，不扫描其他会话或其他成员私有数据库。

文件开头说明范围与条数，主体是完整时间线，末尾单列当前任务与成果快照：

- 会话消息与非重复会话事件；同一消息对应的 app_event 不再重复正文。
- 任务活动、版本建立与确认、补充原话、接收及每轮读取回执、执行授权、材料快照、角色调整、恢复预算和相关系统事件。
- 本地助手工具回执，包括实际文件读取返回值；已有 Codex/执行助手事件，包括保存的命令、输出及错误。旧版协调工具与固定授权文件读取也保留。
- 问题与回答、执行阶段、阻塞、停止协调、模型尝试错误、后台处理、实际运行结果和附件清单的当前快照。附件列名称、路径、字节数、哈希等已有字段，不嵌入二进制文件。
- 新的本机归档／恢复列表操作持久化为会话活动，包括批量归档。重复设置相同偏好不制造新活动；归档不改变任务执行与发送状态。

不导出身份配置、能力哈希、结构化凭据字段和模型内部思考。上下文保存事件保留任务引用，不嵌入内部固定提示词。用户原文、工具参数、命令和输出可能自行包含私人信息，因此仍需在分享前检查；这不是对自由文本的通用秘密识别保证。

## 时间与事实边界

每个已知时间使用完整日期、秒及 UTC 偏移。会话消息/活动是本机保存时间；远端任务活动采用原有消息携带时间，不将其冒充对端接收时间。跨机时钟可能不同；同秒时间按来源读取顺序稳定排列，成员内顺序和运行编号保留在条目里。

个人库 schema 14 → 15 仅为 `events` 和旧版 `model_steps` 各增加可空 `created_at`，旧行不回填、不改写事件正文。新执行活动、旧版消息工具回执、本地助手及旧版协调工具 trace 在落盘时记录秒级时间。没有时间的历史工具/执行活动单独列在“时间未知”区，保留来源内部顺序，不推测其相对时间。

可变记录的创建时间不能当成最终状态发生时间：问题的回答、运行状态、传输状态等明确放在当前快照；有对应历史事件时另在时间线展示。输入读取不等于采用，文件生成不等于送达，任务状态不构成科研结果正确性证明。未同步的远端记录、未持久化的历史活动和操作系统每一次文件访问不在完整性承诺内。正在运行的会话可以导出，之后发生的活动需再次导出。
